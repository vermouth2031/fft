# IQ 信号演示包

本包包含 **22 个 IQ 输入、53 组采集设置与有限回放参考、3 张软件预览图**。输入均为 160 MSPS、小端交错有符号 I16/Q16，每对 IQ 占 4 字节；FFT 每窗 16384 对 IQ。所有输入均与原演示包 SHA-256 一致。

这些结果是已有 AMD 位精确 FFT 软件参考和活动区间软件参考。发布时保留了原数值；**本次没有连接开发板、重新采集或重新验收硬件**。参考 JSON、预览图和离线报告都不应当作新板测记录。

## 开始演示

从仓库根目录运行 `Open_IQ_Monitor.cmd`，在“输入 IQ 文件”中选择本目录的 `.bin`。先阅读 [现场演示路线](先看我_现场演示路线.txt)，按 [完整参数对照](文件说明与参数对照.txt) 切换设置。

比较“几条突发”和精确长度时，取消“循环回放”，持续秒数保留 10。每次比较前清空 ton、toff、kon、koff，再按相应方案填写。digital-zero 使用 legacy + fixed，四个手动框均留空。

| 文件 | 主要展示内容 |
| --- | --- |
| 01 综合双音阶梯 | 幅度变化、正负双峰、谱峰与带宽中心不同、跨窗测长、窗口 RMS 与突发 RMS 不同 |
| 02 幅度阶跃 | 低、高幅度约 1:3；补充 02A/02B 可稳定对比卡片 |
| 03 正负双音 | -30 MHz 与 +20 MHz 两个峰；带宽约 50 MHz |
| 04 线性扫频 | rect/hann 的频谱和 99% 带宽变化，时域 RMS 保持 |
| 05 跨窗突发 | 跨越两个 FFT 窗的同一段 8192 点、51.2 μs 突发 |
| 06/07/08 OFDM | 窄带、宽带及整体 +25 MHz 频移 |
| 09 满带 OFDM | 接近完整 160 MHz 复 IQ 频率跨度的宽带信号 |
| 10 含噪双突发 | 固定门限、背景估计与数字零反例 |
| 11 零间隔阶梯 | gap=32 分段，gap=2048 合并；同时展示幅度、频率阶梯 |
| 12 背景中强弱双突发 | legacy/fixed、legacy/quiet-prefix、robust/quiet-prefix、手动参数及错误背景前导 |
| 13 确认点数 | kon=1024 拒绝短脉冲，koff=2048 合并长段 |
| 14 连续单音 | rect 单 bin 与 Hann 主瓣展宽；起点未确认、停止截断标志 |
| 15 全零 | RMS/峰值为零、NO_POWER、无突发长度 |

`对照补充/` 另有 7 个输入，用于单窗口稳定卡片、非整数频点泄漏，以及 31/32 点零间隔边界对照。

## 四个精选入口

[favorites.json](favorites.json) 提供原四文件精选路线的映射，直接选对应规范文件即可，无须再复制一组相同 IQ。

| 精选入口 | 实际文件编号 | 用途 |
| --- | --- | --- |
| 01 | 01 综合 | 先展示幅度、频点、带宽、跨窗长度 |
| 02 | 06 窄带 OFDM | 展示 OFDM 频谱，与 07/08 比较 |
| 03 | 11 零间隔阶梯 | 切换零间隔、模式和窗函数 |
| 04 | 12 背景强弱双突发 | 切换高级门限档位、策略与手动参数 |

上方卡片主要显示最近 FFT 窗口；长度卡显示最近一段突发。它们不一定统计同一段时间，频谱快照也有自己的窗口编号。

## 离线检查与工具

以下命令从仓库根目录执行，不连接开发板。

```powershell
python -B scripts/check_iq_showcase.py
python -B examples/iq_showcase/tools/generate_iq_showcase.py --inputs-only
python -B examples/iq_showcase/tools/verify_saved_capture.py "实际采集目录"
```

第一条仅需 Python 3.11+ 标准库，检查 22 个输入的 SHA、点数、53 组参考及源码绑定、配置合法性、精确时域 RMS/峰值、频率换算和快照元数据；它不会重新计算 AMD FFT。第二条需要 NumPy，重新合成并核对所有输入，不改已有参考；历史 8 份输入直接读取本包规范 IQ 文件作为种子。第三条需要原验证脚本的 NumPy 依赖，只核验已经保存的真实有限采集，会在该采集目录另存 `showcase_validation.json`。循环采集没有本包对应的完整数值参考，会被明确拒绝。

完整重建参考和预览还需要 Matplotlib，以及与 `tests/fft_reference.py` 相匹配的 AMD xfft v9.1 位精确模型。模型不随本包分发，也不会由上述完整性检查下载。完整重建命令为：

```powershell
python -B examples/iq_showcase/tools/generate_iq_showcase.py
```

生成器会校验输入和重新计算的数值是否等于已审阅参考；遇到内容不同的同名 IQ 文件会停止。`--project` 可显式指定仓库根，`--source-demos` 可显式指定包含历史 `vectors/` 的源目录；两者默认均不依赖原电脑的目录。`--out` 必须在所属仓库内部。完整生成会写参考与图，日常演示不需要运行生成器。

## 文件与溯源

- [manifest.json](manifest.json)：输入、推荐方案、精确数值与资料来源。`project` 相对于本演示包，输入及参考文件名相对于本包。
- `参考结果/`：53 份有限回放软件参考。`bindings` 键均相对于仓库根，包含源码、便携工具和输入的 SHA-256。
- [publication_provenance.json](publication_provenance.json)：原清单、原工具和原参考的 SHA；各参考数值部分的独立摘要用于证明包装改造没有改动原数值。
- [portable_validation.json](portable_validation.json)：本次发布包的标准库离线检查。
- [离线验证报告.json](离线验证报告.json)：原软件验证及历史采集兼容性结果，已移除个人目录。其历史结论与本次发布检查分开记录。
- `预览图/`：软件参考绘图，图中已注明未重新上板。

已保存采集核验工具会先检查仓库相对绑定，再在系统临时目录生成绝对绑定副本，供原 `scripts/verify_board_capture.py` 使用；临时副本随核验结束清除。原验证脚本和本包参考文件不会因此被改写。
