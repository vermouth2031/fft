## 自动检查

GitHub Actions 的 `Host checks` 分为两个 job。当前软件 job 检查 Python 语法、UDP 协议、检测器与帧长参考模型、五信号历史归档，以及新演示包的文件、SHA-256 和参考绑定。冻结硬件证据 job 单独检出固定历史提交，校验该提交上的原始源文件与历史板测证据。

修改当前 GUI 不会被解释为已经重新通过板卡验收。新的 53 组参考场景是有限输入的独立离线预期，循环回放和手动中止产生的截断记录需要按实际采集语义理解。重新生成 FFT 精确参考需要 Vivado/AMD C model，不会在普通 CI 中自动下载或执行专有工具。

## 后续改动

后续软件修改从本分支或固定标签建立功能分支，通过 Pull Request 审阅差异。通过检查后再决定是否合并。硬件修改应建立独立分支，重新生成并核对构建身份、镜像和对应板测证据；新的板测结论记录到新批次。

已发布的版本标签、附件及历史证据保持固定。下一版使用新标签，避免覆盖既有下载。版本页附件附带 SHA-256；下载后可用 PowerShell `Get-FileHash -Algorithm SHA256 文件名` 核对。
