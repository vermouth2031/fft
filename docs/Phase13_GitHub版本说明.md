# Phase13 GitHub 版本说明

最终建立/保持时序余量为 +0.007/+0.050 ns。LUTRAM 5740，两个回放 Bank 各32768对IQ、输入FIFO4096、频域及突发记录各128条、快照1024点均保留。固定FFT点数下，提高采样率会增大频率格宽，不能宣称以Hz衡量的分辨能力保持不变。

完整仿真逐点核对1048576个FFT复数输出；RAM真板通过79项数值检查、80896个快照值、272项宽带检查、1000次DMA切换及故障注入、60/300秒持续测试。SD写入经过完整读回散列核对，系统复位后79项复验通过。旧启动镜像保留在SD上的 `B1CF665D.BIN`。

2026-10-13 用户确认真实断电再上电后，仅通过网口确认自动启动到第九版 `4757a33c02eed50a403db87d09cb091f`，初始 epoch=0、错误=0。未使用 JTAG、下载程序或执行系统复位。冷启动后的 79 项数值检查（80896 个快照值）及 300.000 秒满带 OFDM 持续运行全部通过，完成 8091 次 Bank 切换；频域记录缺口、UDP 丢包和 DMA 错误均为 0。实测最大分析/发布时间为 219.775/219.993750 µs。完整证据见 [冷启动验收](../reports/phase13_boot_acceptance.json)。

160 MSPS 是 FPGA 回放 Bank 的消耗速率，不表示千兆网口连续供应同速率的全新IQ。99%占用带宽按两端各排除0.5%功率统计；这是项目采用的测量口径。未集成外部ADC，既有低信噪比和短突发边界仍适用。

本轮还将64个回放RAMB36的128个A/B原生端口使能改为按需活动，最终布线网表验证通过。第五版的意外POR在第九版上述测试中未复现；电气根因未确定，约0.2秒间隔的板载平均监测不能排除短暂供电扰动，也不足以量化独立功耗收益。
