# 参考、复用与原创范围

本工程按用户的第一版方案实现，主 FFT 使用 AMD LogiCORE FFT v9.1，由本机 Vivado 2026.1 生成。赛题是否允许厂商 FFT IP，需以比赛最终口径为准。

| 来源 | 本工程参考或采用内容 | 范围 |
|---|---|---|
| [nanamake/r22sdf，固定提交 f7dca6e](https://github.com/nanamake/r22sdf/tree/f7dca6e548e1370b69a09382d30609ee14ba4a57) | 流水 SDF、位逆序输出、停顿与使能语义检查 | 结构参考；没有复制其 RTL，也没有声称实现了自主 8192 点 FFT |
| [owocomm-0/fpga-fft，固定提交 c64c89e](https://github.com/owocomm-0/fpga-fft/tree/c64c89e706091f69b68fa1d416322f208fe75270) | 大点数存储布局、精度与资源权衡、时序验证方法 | 未移植生成器或 RTL；未采用其器件性能作为本板结果 |
| [ZipCPU/dblclockfft，固定提交 3378b77](https://github.com/ZipCPU/dblclockfft/tree/3378b77d83a98b06184656a5cb9b54e50dfe4485) | 流接口暂停、精度配置和测试组织 | 思路参考；未编译生成器或复制生成核 |
| [Digilent vivado-boards](https://github.com/Digilent/vivado-boards/tree/master/new/board_files/zybo-z7-20/A.0) | Zybo Z7-20 器件、DDR、MIO 与外设预设 | 实际采用，文件在 `vendor/boards`，保留各文件 MIT 声明；发布清单记录文件 SHA-256 |
| [AMD PG109](https://docs.amd.com/r/en-US/pg109-xfft/Configuration-Channel) | FFT 配置通道、缩放、索引、AXI Stream 与位精确模型 | 实际采用 FFT IP，接口与本机生成模板核对 |
| 本机 AMD embeddedsw lwIP 模板与 xilffs | Zynq 网络、驱动、FatFs 文件服务、FSBL | 实际采用依赖；生成文件保留原许可证；应用协议和 SD 测试程序为本工程代码 |

开源 FFT 项目的文件许可分别见原仓库和上级 `开源项目核查.md`。本工程没有引入这三个项目的 RTL，因此不将其许可证混写为本项目自研 RTL 的许可证。实际随包分发的 Digilent 文件保留版权文本。

自定义 RTL 范围：IQ 回放及控制、AXI-Lite 寄存器、时域功率/幅度/突发检测、加窗适配、频谱功率与双缓冲、99% 带宽、定点运算、跨域连接、结果配对和环形队列。自定义软件范围：UDP 应用协议、SD 回放测试、PC 接收/展示/比较、构建和发布检查。

不把外部项目的已发表性能、方案预算、软件参考、RTL仿真或实际板测混为同一类证据。静态构建与实板验收分开记录，当前通过范围见 [验收状态](验收状态.md)；实板结论必须关联到具体源码、位流、固件和输入数据。
