# 答辩讲稿与预计提问

配合 12 页答辩稿使用，建议技术陈述约 10 分钟、现场演示另留 2 分钟。涉及性能数值时，以最终交付版本的完整验收报告为准；候选结果应明确标注候选名称。个人姓名、团队分工和真实板卡照片未提供，不填写推测内容。

## 逐页讲稿

### 1. 项目介绍（30 秒）

我们在 Zybo Z7-20 上实现了数字 IQ 分析器。输入是 I、Q 各 16 位的复数数据，PL 按每秒一亿对 IQ 处理。项目输出数字幅度、突发包络长度、谱峰和 99% 占用带宽。电脑负责输入文件装载与结果展示，采集开始后的逐样本处理由 PL 完成。

### 2. 比赛要求（50 秒）

位宽、采样率、FFT 点数和处理时间分别给出实现值与原始证据。8192 点 FFT 对应一个 81.92 微秒的输入窗口，但这只是采样时长，不能当成整体分析延迟。比赛未补充的术语采用项目当前定义，并清楚说明外部实时输入、协议帧和调制载频尚未纳入当前实现。

### 3. 系统结构（60 秒）

电脑通过以太网将最多 32768 对 IQ 装入板内 RAM，完整读回确认后启动。100 MHz 源域同时驱动时域测量和异步输入 FIFO。125 MHz FFT 域完成加窗、FFT 和完整频谱测量，频域结果再跨回源域封装。PS 只做控制、文件和结果传输，网络带宽不决定 PL 的逐样本速率。

### 4. 幅度与包络长度（55 秒）

幅度从原始 I、Q 的平方和得到，输出峰值和 RMS，单位是数字码值。包络长度有门限检测和数字零间隔检测两种模式。robust 档要求输入具有明确的静默前缀，以估计噪声背景；它不是自动识别任意环境的黑盒算法。起止点用样本区间表达，输入截断等异常保留标志。

### 5. 频点与带宽（60 秒）

谱峰取功率最大的 FFT bin。99% 带宽按频率升序累计全部 8192 个 bin，两端各去掉约 0.5% 的能量，取两个边界之差。带宽中心是边界中点。调制信号的最高功率 bin 不一定在载频位置，所以界面不能把谱峰直接叫载频。1024 点快照仅用于画图，测量始终使用完整频谱。

### 6. 扩展带宽（65 秒）

新增波形包含完整 OFDM 符号、循环前缀、空置 DC、随机 QPSK 或 16QAM 数据和导频。训练 seed 只用于冻结统一增益，正式 seed 独立。初始三档用于观察跨度与实际占用带宽的关系；次级 98.14453125 MHz 设计跨度档，在本次组合版本完整回归中，内部窗最小实测为 96.997070 MHz。边沿窗和跨 Nyquist 用例单独保留，不能挑选最宽的一窗代表整体成绩。

### 7. 延迟（45 秒）

从窗口第一个 IQ 被 PL 接受开始计时，到分析结果完成结束。另报告写入板内结果缓冲的发布时间。原四路版本最大分析为 183.41 微秒，本次八路组合版本完整验收最大分析为 175.23 微秒、最大发布为 175.57 微秒，改善 8.18 微秒，主要来自频谱扫描段。全部正式成绩对应同一个构建 ID。

### 8. 验证方法（65 秒）

第一层用 AMD 位精确模型逐点比对 FFT 和定点测量。第二层用已知输入真值评价检出、边界和带宽算法。第三层检查真板数据完整性、配置、序号、时戳和吞吐计数。数值实现完全一致，也可能在低信噪比下出现算法不检出；这些情况在报告中保留。持续回放验证运行稳定性，独立随机输入验证覆盖范围。

### 9. 适用边界（55 秒）

独立噪声研究共使用 3153 个不重复块，总时长 1.03317504 秒。三个噪声幅度层都没有观察到虚警，但有限零事件不等于真实虚警率为零。5 dB 的正常检出率和 0 dB 的失败情况应一起展示。离线单音插值有改善，但尚未接入硬件，不能算作 PL 延迟以内的载频能力。

### 10. 现场演示（50 秒，不含等待）

打开演示入口，先运行数字零背景包络，再看单音峰频，最后运行宽带 OFDM。指明当前窗口、门限、采样率和 PL 延迟。停止后展示原始记录、采集完整性和数值参考核验结果。若网络暂时中断，按恢复流程重新连接，保留失败记录，不用一张旧截图替代当前采集。

### 11. 优化取舍（45 秒）

八路扫描保持全部 bin 和测量语义；构建 ID 与跨域计数用于识别实际镜像并检查吞吐。125 MHz 源时钟实验虽然没有负时序，但只有 0.029 ns 建立时间裕量，低于预定门槛，本轮不晋升。实际输入仍为已验证的 100 MSPS。

### 12. 复现与交付（20 秒）

交付包含源码、对应 bit/XSA/ELF/BOOT、原始记录、参考、构建和启动证据，以及包内文件散列。现场使用与验收一致的镜像。项目明确区分已经完成的功能、实验候选和需要赛方进一步定义的范围。

## 预计提问与回答要点

| 提问 | 回答要点 |
|---|---|
| 100 MSPS 是怎样得到的？ | PL 源时钟 100 MHz，每拍一对 IQ。用实际时钟约束、发出/接收/FFT 计数和停止后的守恒检查提供证据。不是网络上传速率。 |
| 能否接外部实时 ADC？ | 当前输入为板内 RAM 回放。外部 ADC 需要确定器件、接口、电平、时钟和输入约束，当前没有完成该链路。 |
| 16bit 是否表示 16bit 有效精度？ | 表示数字输入位宽，未对模拟链路 ENOB 作声明。 |
| 为什么采用 AMD FFT？ | 现有题面未明确禁止厂商 IP。自有 RTL 负责加窗、测量、跨域、控制和结果封装；FFT 内核来源明确。若禁止厂商内核需另行设计。 |
| 8192 点是否只是零填充？ | 正式固定窗口包含 8192 个实际输入样本；FFT 点数和输入窗口在记录与参考中对应。 |
| 显示只有 1024 点，是否减少了测量点数？ | 显示按每 8 个 bin 取最大值；CDF、谱峰与带宽仍使用完整 8192 点谱。 |
| 为什么带宽接近采样率？ | 输入为复数 IQ，完整频率轴约为 −Fs/2 到 Fs/2。报告的是特定未跨 Nyquist 波形的实际 99% 占用带宽。 |
| 可以任意频移同样宽的信号吗？ | 不能。宽信号接近频轴边界后会跨 Nyquist；这类输入作为边界实验，不计入未折返带宽成绩。 |
| 96.997070 MHz 是否适用于所有输入？ | 这是指定 OFDM 规格、增益、seed、窗口和镜像下的内部窗最小值，不能推广到任意波形或频移。 |
| 如何防止只挑出好看的随机输入？ | 训练与正式 seed 分离，先冻结规格、共同增益和门槛，报告全部用例与内部窗最小值。 |
| 为什么不把谱峰叫载频？ | 宽带调制最大谱线会随数据变化，可能偏离真实载频数 MHz。载频估计需要信号模型与独立验证。 |
| 帧长指什么？ | 门限突发或数字零背景下的包络样本长度，使用左闭右开区间；不表示任意协议的数据帧字节数。 |
| 连续 300 秒是否表示 300 秒独立信号？ | 表示重复向量的持续运行稳定性。独立信号量另按不同输入和不重复噪声块统计。 |
| 零虚警是否证明虚警率为零？ | 不证明。每个噪声层的有效观察时长约 0.334 秒；条件性 Poisson 95% 上界约 8.98 次/秒。 |
| 为什么 0 dB 不保证高精度？ | 信号、噪声与门限确认机制共同限制检出和边界。保留失败，不把数值参考一致误写成算法准确。 |
| 八路扫描为何没有让总延迟减半？ | 只缩短频谱后处理的扫描段，输入采集、FFT、跨域和幅度运算仍需时间。 |
| 125 MHz 实验是否成功？ | 完成合法时钟与物理实现研究，但裕量不足而未晋升，没有 125 MSPS 真板验收或发布镜像。 |
| 构建 ID 是否是 bitstream 的 SHA？ | 不是。它是 RTL/配置等构建输入散列的 128 位截取。bit、XSA、ELF 和 BOOT 的 SHA-256 另行记录。 |
| 跨域计数是否同一时刻锁存？ | 不是。各域原生计数通过安全快照传输；只在停止、排空后检查精确守恒，运行时不把不同瞬间的差异当成丢样。 |
| 启动是否依赖电脑 JTAG？ | 本次镜像已完成 SD 写入读回、复位启动，以及用户实际断电上电后的纯网口验收。启动不需要电脑重新下载；证据见冷启动报告。 |

## 演示失败时的操作

1. 停止当前采集，记录错误、当前 epoch 和日志目录，确认只有一个控制端。
2. 检查网络连接后重新查询身份与状态，使用同一个已核验预设重新采集，并保存到新目录。
3. 如需重新装载镜像，必须使用与当前验收对应的产物，并清楚说明此次启动方式。
4. 现场无法恢复时展示此前真实原始证据并说明发生了连接故障，不声称旧截图来自当前实时采集。
