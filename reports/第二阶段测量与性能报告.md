## 已识别的适用范围

- **固定门限漏掉低幅持续单音：** 1、16、256 码值都未产生门限突发，但频域测量仍与参考一致。256 码的 16 点功率和恰好为 TON=1048576，而启动条件为严格大于 TON，因此不触发。这是当前参数的适用范围，不能宣传任意幅度均能测长。
- **等幅双音拍频造成分段：** 1 bin 间隔得到 5 条、2 bin 间隔得到 9 条门限突发，两种窗结果相同，均符合参考。输入的整个非零区间不等于门限检测区间；S2 需要继续量化误拆分等指标。
- **NO_POWER 不总等于原始 I/Q 全零：** 8 个全零窗口及跨窗突发的 5 个边沿／空窗口共 13 条 NO_POWER，其中 Hann 的第 0 窗含少量原始有效点，但窗权重及 FFT 定点量化使输出谱功率为零。原始时域能量仍单独准确保存。
- 64 条 RESOLUTION_LIMITED 与参考一致；其余 147 条频域记录无状态标志。±49MHz 用例未跨越 Nyquist，不构成 100MHz 有效带宽或环绕带宽证明。

## 实现

`tests/fft_reference.py` 提供上下文管理器 `FFTReference`，显式创建和释放 AMD C 模型；导入不生成黄金文件。完整保留 24 位输入、18 位旋转因子、收敛舍入、缩放序列 `[3,2,2,2,2,2,1]`、Hann 系数及整数 99% 分位口径。模型溢出直接报错。`make_golden.py` 默认行为兼容，并支持输出到独立目录核对。

`data/qualification/s1_pilot.json` 是首批样例规格。`tests/generate_qualification_vectors.py` 据此生成独立二进制和清单，保留采样率、窗口、检测模式及门限、幅度、频率、设计区间、无噪声／无偏置声明及 SHA-256；输入超范围时报错，不裁剪。所有本轮信号为确定性信号，seed=null。

`scripts/validate_measurements.py` 提供 prepare/capture/verify 三个入口。参考绑定实际输入、规格、生成器、校验脚本、窗系数和厂商模型散列；不以文件名推断真值。当前明确仅支持 100MSPS、8192/16384/24576/32768 点有限回放及基线门限参数；噪声、偏置、自定义门限和循环输入需后续扩展，现阶段明确拒绝。

采集时先执行原 16 个黄金组合的有限实板回归，再运行新矩阵。每组核对频域数值、时域能量／幅度、检测区间、标志、序号、时戳和可用快照。采集后读回完整采样／FFT、回放、窗、ROI、门限与确认配置，要求 epoch/config_id 与原始记录相同。

`errors.csv` 按每个 8192 点窗口分别保存设计频率、量化输入 NumPy 谱峰、AMD 参考峰频率、硬件峰频率，以及硬件峰值／RMS、量化输入与原浮点输入的绝对／相对误差和标志。零值相对误差留空；零功率、低幅、频带边缘、双音及突发边沿不混入正常单音精度统计。峰值／RMS 单位为复包络数字码值，不解释为电压或未定义的 dBFS。

## 验证口径

首批为 28 个波形 × 两种窗 = 56 组，每组 32768 点、四个 FFT 窗口。包含 7 个正负整数频点、4 个非整数频点、±49MHz、8 档额外幅度（含 1/16 码低幅边界）、零输入、双路负满幅、数字零跨窗突发及 1/2/8/64 bin 间隔等幅双音。

正常单音工程目标为峰值误差不超过 1 bin，并符合最近 bin 预期；100MSPS/8192 的 1 bin = 12207.03125Hz。硬件与位精确参考完全一致，以及相对设计目标是否满足工程目标，分别保存状态。低幅输入低于门限时不把未检出解释为硬件错误。

原 16 组合共 524288 个复数 FFT 输出以及 golden_results.json、test_iq.mem、Hann 文件要求逐字节一致。新增工具测试还覆盖导入无副作用、模型生命周期、零／负满幅边界、非法参数、溢出拒绝、清单篡改，以及对真实历史板测记录改名后用显式参考核对和故意破坏参考的负向检查。

完整仿真使用原 `run.ps1 -Action Sim` 入口，并在真实运行成功后刷新 simulation_provenance；新增测试脚本、规格和校验入口已纳入来源记录。历史硬件与实板报告保留。

## 复现入口

以下路径仅作示例，每次换用新的输出目录；先关闭其他采集控制端。

```powershell
python tests/generate_qualification_vectors.py --spec data/qualification/s1_pilot.json --out build/qualification/my_vectors
python scripts/validate_measurements.py prepare --manifest build/qualification/my_vectors/manifest.json --out build/qualification/my_reference
.\scripts\run.ps1 -Action Sim
python scripts/validate_measurements.py capture --references build/qualification/my_reference/index.json --out captures/my_measurements --board 192.168.1.10
python scripts/validate_measurements.py verify --run captures/my_measurements
python scripts/package_validated.py --check --measurements captures/my_measurements
python scripts/package_validated.py --out release/my_measurement_delivery --measurements captures/my_measurements
```

每条命令成功后再执行下一条。资格验证生成物含本机绝对路径；交付包内保存相同项目相对路径，跨电脑可用 `scripts/verify_delivery.py` 检查所有文件散列。重新执行 AMD 模型需本机 Vivado 安装及重新生成参考，不能把移动路径后的引用当成原运行身份。
