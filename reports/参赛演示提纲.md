# 参赛演示提纲

本页配合 `第三阶段完整验收报告.md` 和 `第三阶段条件性优化决策.md` 使用。指标以原始验收记录为准；照片、队伍信息和最终录像由参赛方补充。

## 一页硬指标

| 指标 | 已实现版本 | 验证口径 |
|---|---|---|
| I/Q 位宽 | 各 16 bit | 输入格式、RTL、实板读回 |
| 输入处理速率 | 标称 100MSPS | PC 预装载，板内 RAM 回放；每 10ns 一对 I/Q |
| FFT 长度 | 8192 | AMD 位精确模型、完整仿真与板测参考 |
| 分析时间 | 四路扫描后基础完整套件最大 183.41µs | 首有效输入至频域结果；全部矩阵最大值见第三阶段完整报告 |
| 时序裕量 | setup 0.542ns、hold 0.016ns | 同一实际时钟约束；没有通过放宽约束取得成绩 |
| 频率精度 | 本轮适用单音最大误差 0.49001536 bin | 1 bin=12207.03125Hz；不是任意信号 1Hz 精度 |
| 带宽 | 整个 8192 点谱的 99% 占用带宽 | 本轮逐档 min/median/max 及最宽档 60 秒证据见完整报告 |
| 帧长 | 数字零模式与门限模式 | 零背景边界可精确；带噪门限效果另列适用范围 |
| 启动 | SD 网络固件 | 新镜像的实体SD读回、复位与物理冷启动状态，以第三阶段完整报告为准 |

时间、频率采用标称板载时钟，未使用计量校准设备。工程不含外部 ADC 或射频接收前端。

## 一页适用范围

| 输入条件 | 结论与限制 |
|---|---|
| 精确零背景 | 数字零模式按非零支撑区间测长；短间隔会按 gap_min 合并 |
| 带噪背景 | 数字零模式不适用；固定门限可能将多帧误合并 |
| 有已知前导静默区 | 正式CLI/GUI选择robust，主机对前1024点估计背景功率；16点能量窗，ton/toff倍数3/1.75，kon/koff=16/8，START前读回校验 |
| 独立验收 30/20/10dB | 幅度4096码、未成形QPSK、每符号2点及AWGN；每SNR各500个突发均匹配且符合±32点起止容差 |
| 独立验收 5dB | 500个匹配，496个正常，正常率99.2%；1个真值被拆分；125个独立输入seed，每输入4个突发 |
| 相同历史8192码输入 | 5dB正常数由71/100提高到97/100；30/20/10dB各由99/100提高到100/100 |
| 独立验收 0dB | 500个已知突发均未满足匹配规则，22个真值出现拆分，记录为适用范围失败 |
| 独立纯噪声 | 256块共0.08388608秒内观测虚警0；短时零观测不能宣称长期虚警率为零 |
| 大DC、未知静默区、噪声漂移 | 不属于本轮robust保证；没有板内DC补偿或在线CFAR |
| 低幅、双音、频带边缘 | 单独保留状态和误差，不混入正常单音精度成绩 |
| 跨 Nyquist 边界 | 当前线性 CDF 不支持环绕最短占用带宽；排除出扩大带宽成绩 |
| 连续回放 | 重复同一 32768 点输入块，证明持续处理稳定性；不等同持续独立随机数据 |

## 原理框图

```mermaid
flowchart LR
  PC[PC 波形生成与输入清单] -->|以太网预装载| ARM[Zynq ARM 网络固件]
  ARM --> RAM[PL I/Q 回放 RAM]
  RAM -->|100MSPS| TIME[幅度与两种突发检测]
  RAM --> WINDOW[矩形或 Hann 窗]
  WINDOW --> FFT[AMD 8192 点 FFT]
  FFT --> SPEC[四路扫描：完整谱峰值与 99% CDF 带宽]
  TIME --> RESULT[结果构造与缓冲]
  SPEC --> RESULT
  RESULT --> ARM
  ARM -->|UDP 结果| GUI[PC 显示与原始记录]
  GUI --> VERIFY[位精确核验与误差统计]
```

FFT IP 与厂商驱动属于第三方；回放控制、窗口衔接、检测、频谱统计、结果协议和验证工具的职责见源码与第三方声明。

## 演示顺序

1. 展示实际 Zybo Z7-20、SD、USB 和网线连接。启动网络固件，说明已保存的冷启动证据；若现场断电，应另存本次启动后的采集记录。
2. 运行正、负频点和非整数频点；解释 FFT bin 间隔以及量化误差。
3. 改变输入幅度，展示复包络峰值、RMS 与参考差异。数字码值不直接转换成未校准物理电压。
4. 同一突发分别展示门限测长与数字零测长；用相同历史输入比较legacy与robust，展示实际门限读回及5dB边界改善。说明静默区须由用户确认，0dB仍失败。
5. 展示宽带分档 min/median/max，指出符号率、RRC 理想支撑、实际 99% 带宽的差别。
6. 展示最宽稳定档 60 秒连续结果，以及完整性、错误和逐条数值检查。
7. 展示本轮高扇出复制和四路扫描的实际时序、资源及延迟收益。另列较长能量窗、DC、Realtime及125MSPS未晋升的证据，明确采样率仍为100MSPS。

每次只运行一个采集控制端，GUI 与资格验证脚本不要同时启动采集。重现矩阵时使用新输出目录，保留旧记录。
