# Zybo Z7-20 数字 IQ 分析仪：最终验收与交付说明

日期：2026-09-17。当前结论：100 MSPS 内部数字回放基准版本已完成 RTL 仿真、布局布线、SD 和以太网实板验收，并完成突发压力、通信故障恢复、图形界面和快照检查。

## 赛题指标与实际证据

| 项目 | 已实现 / 已验证 |
|---|---|
| 数字 IQ 位宽 ≥12 bit | I、Q 各 16 bit，有符号；含双路负满幅测试 |
| IQ 速率 ≥100 MSPS | 标称 100 MHz，每拍一对 IQ；最长 60 秒连续样本、窗口数和时间戳逐条核验 |
| FFT ≥8192 点 | 8192 点、24 bit AMD FFT，524,288 个复数仿真输出与 AMD 位精确模型一致 |
| 分析时间 ≤2 ms | 实板最大分析 199.78 µs，最大发布 200.12 µs，按名义 100 MHz 计数换算 |
| 幅度 | 原始 IQ 峰值/RMS/能量；单音幅度减半时实测由 8192 变为 4096 码值 |
| 帧长度 | 能量门限定义的突发长度；64/512/4096 样本短突发及跨窗、部分突发均按整数参考核对 |
| 频点、带宽 | 正负 25 MHz 单音、两种符号速率 QPSK、99% 占用带宽与中心频率 |
| FPGA 实板 | Zybo Z7-20 / XC7Z020，SD、DDR、JTAG、UART、千兆以太网均已实际运行 |

实现资源：LUT 11,822（22.22%），寄存器 19,295（18.13%），BRAM 90.5（64.64%），DSP 53（24.09%）。布局布线后 setup 裕量 +0.109 ns、hold 裕量 +0.008 ns，CDC Critical=0，无未约束内部端点。时序余量较小，改动 RTL 或时钟后必须重新实现验收。

## 已完成的实板验收

1. **SD 自动测试**：4 轮、64 组；256 条频域及 56 条突发记录全部精确匹配参考。见 `SD实板验证报告.md`。
2. **网络连续服务**：单音、10 秒与 60 秒，合计 854,196 条频域、213,550 条突发记录全部逐条核对；正常轮次零丢包、零队列丢弃。见 `以太网实板验证报告.md`。
3. **突发压力**：每 32768 样本产生两次完整突发，名义 6103.516 次/秒，超过方案 5000 次/秒目标。20 秒请求实际接受 1,998,659,584 对 IQ，243,977 条频域、121,989 条突发，全部接收，突发起止、能量和幅度逐条正确。
4. **异常识别与恢复**：故意丢失一个流包、0.5 秒接收黑洞、0.7 秒停止读取小接收缓冲区，都明确判为不完整。丢失 START 应答时命令重试正常完成。每项之后的新采集均通过。
5. **真实链路中断**：禁用有线网卡 3 秒再启用。首次发现 Windows 将原 UDP 套接字永久置为无效，需 JTAG 停止才能恢复；此失败记录保留。修复电脑端的套接字重建逻辑后，保持原源 IP/端口恢复连接，正确记录硬件队列丢弃与缺包，完成停止并开始下一轮正常采集，重测不需要 JTAG 干预。丢失的数据不会自动补齐。
6. **独立主机时基交叉测量**：使用电脑 `perf_counter_ns` 与 FPGA 源时钟计数器，约 10 秒间隔；计入两端网络读回延迟后，源时钟界限为 99.993272–100.007345 MHz，中点约 100.000309 MHz。电脑时基独立于 FPGA，但未经计量校准，不能代替校准频率计。
7. **GUI**：实际执行定时采集、主动窗口边界停止和离线查看；显示突发长度、采集核验、缺包、错误和最大发布延迟。修正 Windows 缩放和布局后已截图检查。
8. **显示快照**：84 份实板快照、86,016 个功率值与 AMD 整数 FFT 结果经频谱移位、每 8 点取最大值后的结果完全一致。
9. **UART 与启动**：COM4、115200 8N1 捕获 419 字符启动日志，含程序标识、Realtek 千兆协商、IP/掩码/网关。JTAG 装载脚本修复了复位后重新暂停 CPU 的顺序；最后重新从 SD 启动并通过单音采集。

上述正常采集与故障注入结果分开保存。故障轮次的 `capture_complete=false` 是预期的失效检测证据，不能混入零错误验收统计。

## 本次代码修正

- `host/iq_client.py`：Windows 网卡重置后按原 IP/端口重新建立 UDP 套接字；失败轮次显式记录原因；完整性检查涵盖队列丢弃、样本数量和硬件截止时间。
- `host/monitor.py`：显示突发长度及最终核验状态，加载记录时匹配输入参考；改善 Windows DPI 和窗口重绘。
- `scripts/program_board.tcl`、`scripts/jtag_capture.tcl`：复位后重新选择并暂停 CPU，避免 SD 自动启动与 DDR 初始化并发；JTAG 采集加载 XSA 地址元数据。
- 上述改动不改变 RTL、位流、PS 固件或 SD 启动文件，现有 SD 卡无需重写。

## 需要人工或额外条件的事项

- PCB 修订号、板上器件丝印和电源适配器标签尚未拍照记录；不能从芯片型号或 PHY 自动推断 PCB 修订号。
- 主办方是否接受 AMD FFT IP、板内数字回放的具体参赛口径，需要向主办方确认；赛题文字没有明确禁止，工程报告不代替主办方解释。
- 校准仪器的绝对采样时钟精度、外部 ADC / 射频输入和模拟量校准需要相应仪器或外设。

125 MSPS、外部 ADC 接口、自主 FFT 是原方案中的扩展方向，本次交付冻结于已验收的 100 MSPS 基准。它们尚未实现，不作为已取得的加分成果。最长已验证正常连续时长为 60 秒；不将其扩展声称为无限期稳定运行。
