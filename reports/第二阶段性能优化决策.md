# 第二阶段性能优化决策

日期：2026-09-21。默认版本保持 I/Q 各 16 位、100MSPS 板内回放、125MHz FFT 时钟、8192 点 FFT。

## S4：全局时序实验

原布线后 setup/hold 裕量为 0.030/0.004ns。最大扇出网络为 FFT IP 内部 `ce_w2c`，扇出 10489；关键路径约 6.960ns 来自布线。外部复位并非当前最差路径，不能假定增加外部复位流水就能消除该瓶颈。

实验使用 `scripts/phase2_timing_experiment.tcl`。独立加载检查点，运行 `phys_opt_design -directive AggressiveExplore` 和 `route_design -directive Explore`，保存前后全局时序、路径、扇出、资源、CDC、DRC、bus skew 和候选 DCP。原 RTL、约束、厂商 IP 文件与默认硬件产物不变。

实验一加载 `system_wrapper_routed.dcp`。结果 setup/hold 仍为 0.030/0.004ns；Vivado 明确记录已满足 setup/hold，因此跳过物理综合优化、网表未修改。资源仍为 LUT 12359、FF 20030、BRAM 90.5、DSP 53，CDC 无 Critical，DRC 无 Error。该实验未取得收益，不晋升为默认版本。

实验二加载 `system_wrapper_placed.dcp`，从布局检查点重新执行物理优化和布线。最终 setup/hold 同样为 0.030/0.004ns；LUT 从 12359 增至 12361，其余 FF/BRAM/DSP 不变。CDC 无 Critical，DRC 无 Error。两次实验均未达到 setup≥0.10ns 的内部期望，因此保留默认版本，候选 DCP 未烧录板卡。输入检查点、命令和所有输出散列见 `phase2_performance_decision.json`。

## S5：延迟分解与实施决策

`reports/phase2_latency_validation.json` 绑定完整核心仿真的 64 个窗口和原始 `latency_events.csv`。所有阶段使用统一的仿真纳秒时间轴，避免直接相减不同频率的时钟计数。

| 阶段 | 最小 / 中位 / 最大，µs |
|---|---|
| 首输入至末输入 | 81.910 / 81.910 / 81.910 |
| 末输入至 FFT 首输出 | 1.489 / 1.825 / 1.825 |
| FFT 首输出至末输出 | 65.528 / 81.736 / 81.896 |
| FFT 末输出至谱 bank 就绪 | 0.024 / 0.024 / 0.024 |
| bank 就绪至扫描开始 | 0.544 / 0.544 / 0.544 |
| 扫描首点至末点 | 32.792 / 32.792 / 32.792 |
| 扫描末点至扫描结果 | 0.008 / 0.008 / 0.008 |
| 扫描结果至分析完成 | 0.771 / 0.771 / 0.775 |
| 总分析时间 | 183.070 / 199.610 / 199.770 |

首末采样沿间隔为 8191×10ns；包括首周期的 8192 点采样时长为 81.920µs。各列中位数来自各阶段独立统计，不作为某一个窗口的总和；逐窗口分解已验证精确相加。

核心消费端观察结果还需 0.010µs，该事件不等同外围结果环提交、UDP 接收或 GUI 刷新。实际发布延迟仍以实板寄存器和采集记录为准。

**本轮决定不实施每拍扫描 4 点。** 其扫描主体理论节省约 16.384µs，仅占目前最大分析延迟约 8.2%。当前已经满足 2ms 门槛，而全局 setup 仅 0.030ns、BRAM 已占 64.64%；新方案需重做 RAM 分组、四点前缀和、边界选择、双 bank 和快照对齐，并重新完成时序及实板验收。本轮以完成测量能力和明确适用范围为交付重点，保留现有已验证电路。未实现四点扫描，不宣称已达成低于 190µs 的新指标。

## S6：125MSPS 可选档位

**本轮不启用该可选档位。** 尚未形成时序裕量改善并完成实板验收的 S4 新硬件版本。125MSPS 需独立重建采样时钟、吞吐与 FIFO 验证、频率与时间换算、主机及参考模型、BOOT 和冷启动验收；当前这些工作没有执行，不将显示参数变更视作提频。

上述决策依据方案允许的“候选实现或不实施结论”及“可选 125MSPS”范围。S1～S3 的测量交付不依赖这些硬件候选成功。当前启动程序未更换，沿用原硬件对应的真实 SD 与冷启动证据，不宣称本轮重新进行了物理断电测试。
